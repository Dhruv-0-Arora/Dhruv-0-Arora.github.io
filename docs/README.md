# Docs

Working knowledge for anyone continuing this project, human or agent.
Read in this order and stop when you have what you need.

| File | Answers |
|---|---|
| [architecture.md](architecture.md) | How the repo is laid out and how the simulator runs at runtime |
| [world-pipeline.md](world-pipeline.md) | How the 3D world is authored in Blender, linted, exported and shipped |
| [decisions.md](decisions.md) | Why things are the way they are, one entry per decision |
| [content-rules.md](content-rules.md) | What shipped copy may and may not say, and which tests enforce it |
| [history.md](history.md) | What has been done, in order, and what is still open |

Conventions that apply to every file here: plain dash instead of em dash, one sentence per line in long Markdown, absolute dates.
The root `README.md` is the public entry point; these docs go deeper and are the place to record new decisions.
